# 実装ノート

各アルゴリズムを実装する前に、`<algorithm-id>.md` を作って調査結果を記録する。
**実装より先に書くこと。** 書けない項目があるなら、まだ実装を始める段階ではない。

雛形は [_TEMPLATE.md](_TEMPLATE.md)。

## 書くときの約束

- ページ番号・節番号は **PDF を目で見て確認したものだけ**書く
- 保証が確認できない場合は「不明」と書く。推測で埋めない
- 論文と公開実装が違う場合は、**両方**と、今回どちらを採ったか、その理由を書く
- ここで確定させた理論保証は、`docs/sources/algorithms.yaml` の
  `guarantees` と `guarantee_evidence` にも**必ず書き戻す**。
  サイトの保証表はマニフェストだけを見ているので、ここに書いただけでは反映されない
